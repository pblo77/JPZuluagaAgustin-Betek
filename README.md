# Cloud Computing: Laboratorios de Infraestructura y Multi-Cloud

Este repositorio compila las evidencias, arquitecturas y documentación técnica de los laboratorios prácticos desarrollados durante mi formación especializada en **Cloud Computing**. El enfoque principal de estos proyectos es el despliegue, automatización y gestión de infraestructura en los principales proveedores de la nube (AWS, Azure y GCP).

---

## 🛠️ Tecnologías y Proveedores Cloud

* **Amazon Web Services (AWS):** EC2, VPC, S3, IAM, CloudWatch, Route 53.
* **Microsoft Azure:** Azure Virtual Machines, Azure VNet, Resource Groups, Azure Storage.
* **Google Cloud Platform (GCP):** Compute Engine, Cloud Storage, VPC Network.
* **Sistemas Operativos & Servidores:** Linux (Ubuntu Server), Nginx.
* **Conceptos Clave:** Redes, Seguridad Cloud, Escalabilidad, Computación Serverless.

---

## 🚀 Habilidades Demostradas

* **Administración de Servidores:** Configuración y endurecimiento (hardening) de servidores Linux para entornos de producción.
* **Diseño de Redes Cloud:** Creación de topologías de red seguras, segmentación de subredes y gestión de enrutamiento.
* **Mentalidad Multi-Cloud:** Capacidad de adaptar conceptos de infraestructura (cómputo, almacenamiento, redes) de manera ágil entre AWS, Azure y GCP.
* **Documentación Técnica:** Capacidad para registrar procesos, diagramar arquitecturas y validar configuraciones siguiendo estándares profesionales.

---

## 🎓 Certificaciones & Contexto
Estos laboratorios forman parte de mi preparación técnica continua para la validación de competencias en la nube, alineados con certificaciones oficiales de la industria (como *AWS Certified Cloud Practitioner* y fundamentos de Azure/GCP).
